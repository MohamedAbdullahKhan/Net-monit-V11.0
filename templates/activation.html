How to Get a License Key
  1. Copy your Device ID and Activation Code from above.
  2. Send both values to abuabdullah.be@outlook.com or submit a request through InfoXteK.com.
  3. We generate your license key from those two values. The license is completely free; we only need the Device ID and Activation Code.
  4. You will receive your key within 4–7 business days.
  5. Paste the whole key (it starts with NM1-) into the box above and click Activate License.
Note: Each license key is unique to this server's Device ID and Activation Code. A key generated for a different server will not work here. The key is permanent — it does not expire.
